## Proposed Northvale design direction

- **Primary influence:** Nolen Homes (40%) — warm, photography-led, luxury-residential restraint. _(prompt-based)_
- **Supporting:** Black Rock (25%) conversion clarity · HOUS/PARK (20%) typographic scale, near-black bands, whitespace · Baker (15%) operational calm. _(prompt-based)_
- **Emotional impression:** "the roofing company a custom-home builder would hire" — established, unhurried, precise.
- **Typography:** Cormorant Garamond display at larger scale (never <28px rendered — brand hard rule); Montserrat for UI/body; tracked-uppercase eyebrows and buttons.
- **Color:** Navy-950 as the near-black anchor (header, footer, one CTA band). Warm ivory/cream surfaces for content. Gold used only as accent + primary CTA fill (navy text on gold per brand §7.1; gold-600 for gold text on light).
- **Photography:** existing image system untouched; sharper corners, calmer shadows, thin gold rules as accents.
- **Navigation:** dark, hairline-ruled, existing links/CTAs and fluid scaling behavior preserved.
- **Components:** fewer, flatter cards; hairline borders (navy-100 / white-10); 2px radii on interactive elements; 6px on media/cards.
- **Mobile:** same architecture (hamburger + sticky call/text bar), restyled dark panel, fluid type via clamp().
- **Specifically avoided:** announcement bar with invented copy; badge clutter; gradients; glassmorphism; pill-heavy UI; dark-on-every-section; parallax; new JS.
